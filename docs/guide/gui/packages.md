# Packages Guide

Packages in Nitrolaunch allow easy installation of mods, resource packs, and more. By using them, you don't have to worry about dependencies, downloading, what folders to use, or mod conflicts. Everything just works.

![](../../assets/screenshots/gui_packages.png)

## 1. Finding the packages you want

Browse packages using the packages tab at the top.

You can use the repository buttons at the top to change what source you're getting the packages from. By default, you will search all repositories.

There are also filters and a search bar to further narrow down your results.

## 2. Adding packages to an instance

![](../../assets/screenshots/package_page.png)

Click the install button at the bottom of the package page or on one of the versions in the versions tab. Then pick where you want to install it. For modpacks, you can add them to an existing location or create a new instance from it.

![](../../assets/screenshots/package_install.png)

## 3. Viewing and editing packages

![](../../assets/screenshots/instance_packages.png)

By navigating to an instance's page, you can edit and remove packages on that instance.

You can also click the search button to browse for packages that are compatible with this instance.

## 4. Updating packages

You can update packages on an instance by either updating the whole instance, or navigating to the instance page and updating only the packages. To update the modpack, click the button on the modpack.
