# Themes
ID: `themes`

The Themes plugin adds a multitude of themes you can apply to the app.

!!!warning Note
The plugin is only supported in the GUI.
!!!

## Usage
All of the themes can be applied in the settings.

### Custom Backgrounds
There are two custom background themes that let you set your own background image, with a blurred and unblurred version.

Use the `Open Data Folder` button in the GUI to open the folder, and move your background image into that folder with the name `custom_background.png`.
